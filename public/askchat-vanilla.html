Ask Chat — vanilla HTML embed

This page embeds <headlo-ask-chat> with zero framework code. Three <script> tags in the head + a config script + one custom-element tag in the body. No React import, no npm install, no build step.

The on-ask attribute is a composite slug:version:action string. The wrapper auto-loads the matching service bundle on first render — you don't add a <script> for the service.

Editing this page: replace pk_live_… with your own PROP publishable key (from /dashboard/prop) if you're forking. The component and service under headlo-ask-chat must be marked public in the dashboard for anonymous browsers to fetch them.
